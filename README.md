Assignment B1b: Pick-and-Place Pipeline with UR5e + 2FG7 (SIMULATION / LATER REAL IMPLEMENTATION)

What to do: Develop a complete pick-and-place pipeline using the UR5e arm and 2FG7 gripper, building on the validated force-based grasping interface from Assignment 4a.
1) Design and implement a full pick-and-place task pipeline
2) Coordinate arm motion and gripper actions for object manipulation
3) Integrate force-based grasp control into the grasp, lift, transfer, and release sequence
4) Define grasp, lift, transfer, and release behaviors
5) Add basic error handling and recovery behaviors
6) Test representative pick-and-place scenarios and evaluate task success rate

Software needed: MoveIt2, ROS2 Humble, UR5e control stack, OnRobot drivers, 2FG7 gripper interface

Research needed: Pick-and-place task design, sequencing of arm and gripper actions, integration of force-based grasping into manipulation pipelines, recovery strategies for failed grasps or motions

Deliverables: Working pick-and-place application using the UR5e and 2FG7, with force-based grasping integrated into the manipulation pipeline and evaluated on representative scenarios
